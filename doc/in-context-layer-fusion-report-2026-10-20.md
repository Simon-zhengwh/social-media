## 1. 本次解决的根因

上一版虽然有全局参考和独立组件，但成图仍存在两个根因：

1. 参考驱动模式仍把原始商品图作为独立 `image` 图层叠回成品，并在布局计划中保留了巨大的“照片纸/相框”形状。
2. 组件生成只读取全局参考，没有读取“当前海报合成状态”和“目标区域周围内容”。

本次分别从场景层、生成层和数据模型层修复。

## 2. 背景融合改造

### 2.1 移除重复商品图片

参考驱动模式下，全局参考稿已经把用户商品图作为主体输入。干净底图继续保留同一食物场景。

如果此时再把原始商品图叠加回成品，就会重新出现：

- 矩形照片区域
- 奶油纸边框
- 原图与生成场景的光线不一致
- 明显的“照片贴在背景上”效果

修复：

- 参考驱动模式不再添加 `role=product` 的独立图片图层。
- `asset_usage` 只保留 Logo，不再记录重复商品层。
- 后置视觉审查看到的图层从 **21 层** 降到 **12 层**。

### 2.2 移除大面积照片容器形状

新增确定性过滤：

- 面积超过画布 14%；
- id/name 包含 `photo_paper`、`photo_frame`、`image_card`、照片、相框等语义；

这类形状在参考驱动模式中自动移除。实测删除了 `shape_photo_paper` 等照片卡片边框。

### 2.3 满版场景与色彩统一

- 干净底图继续保留完整食物摄影构图，不再拆成“绿色背景 + 矩形食物图”。
- 新增确定性 `harmonize_scene_image()`：轻微提升饱和度/对比度，并叠加低强度深绿色径向边缘分级。
- 该处理只做色彩与暗角统一，不重绘食物，不改变商品内容。

### 2.4 最终图层结构

最终任务：

- 1 个连续场景底图
- 3 个视觉组件：标题、价格、优惠贴片
- 4 个可编辑文字层
- 1 个透明 Logo 图片层
- 3 个手绘辅助形状

不再存在原始商品图片图层或大面积照片边框。

## 3. 上下文感知图层生成

### 3.1 依赖关系

```text
全局参考 + 干净底图
  → 标题组件生成
  → 标题合成到当前预览
  → 价格组件 + 优惠贴片并行生成
  → 最终合成
  → Visual Critic
  → 自动样式/几何修正
```

- 标题是主视觉锚点，必须先串行生成。
- 价格与优惠在标题合成后互不依赖，使用线程池并行生成。
- 实测价格与优惠两次图片请求在约 2 秒内先后返回。

### 3.2 每次组件调用实际输入

每次标题/价格/优惠调用提供 3 张图片参考：

1. 全局视觉参考稿。
2. 当前整张海报合成预览，目标区域有黄色高亮框。
3. 目标区域周围的局部裁剪图。

同时 Prompt 中包含：

- 组件类型与业务语义
- 当前文案原文
- 全局 DesignIntent
- 品牌色板
- 目标区域在画面中的相对方位、宽高比例
- 需要匹配的光线、材质、纸感和笔刷语言
- 透明底/品红底要求
- 禁止文字、Logo、矩形卡片和 UI 贴片

黄色高亮只作为位置上下文，要求模型不得输出该高亮。

实测组件资产元数据：

| 组件 | 上下文图片数（不含全局参考） | 目标区域 |
|---|---:|---|
| 标题 | 2 | 顶部居中，宽 94.35% |
| 价格 | 2 | 底部居中，宽 83.15% |
| 优惠 | 2 | 右上，宽 25.74% |

### 3.3 透明素材提取

仍然使用已验证的品红底方案：

- `#FF00FF` 平铺背景
- Pillow HSV/通道联合阈值
- 透明羽化
- 边缘去品红
- 自动裁切到主体包围盒
- 透明度覆盖率质量门禁
- 失败重试一次
- 最终失败回退到原生文字 + 确定性装饰

这些字段可通过 Scene JSON 保存、版本恢复和图层 PATCH 更新。

## 5A. 价格文字重叠修复

用户反馈 `$66.99/位` 在画面中部出现双层重叠。根因不是 Scene 坐标，而是价格组件素材本身被模型烘焙进了旧价格文字：

- 旧价格素材含烘焙的 `$56.99/位`；
- 用户把原生价格改为 `$66.99/位` 后；
- 原生文字与素材里旧价格叠加。

修复分三层：

1. **价格 Prompt 不接收可读价格文本**：只描述价格丝带的材质、方向和目标区域，明确禁止货币符号、数字、单位和文字。
2. **价格组件改用无文字标题笔刷作为材质参考**：避免全局参考中的旧价格被复制；价格和优惠仍会读取当前合成预览与局部裁剪。
3. **增加烘焙字形检测**：价格素材中大面积奶油/白色连通区域超过 5% 时判定失败并重试；成功后用 `fit=cover` 让丝带铺满价格区域。

真实重生成结果：

- 价格素材高亮字形区域：**1.49%**，通过门禁；
- 新素材没有可读价格；
- 最终画面只保留一个原生 `$66.99/位`；
- 价格丝带填充宽度从 contain 的局部覆盖改为 cover 的完整覆盖。

## 9. 仍存在的限制

- 严格保留用户真实商品图细节的 Mask/Outpainting 路径尚未产品化；当前参考驱动固定采用完整场景方案。
- 背景融合主要依赖完整场景生成 + 确定性分级 + 组件色彩匹配，尚未实现基于深度/光照估计的复杂合成。
- `relations` 目前是结构化语义和审计元数据，尚未驱动自动避让或动态锚点布局。
- 价格/优惠组件如果模型仍烘焙文字，目前依靠字形区域门禁与重试；未接入 OCR 级别的逐字检测。
- 当前正式导出仍由 Pillow 完成，Fabric.js/Konva.js 浏览器导出仍是后续阶段。

## 10. 结论

本次目标的核心链路已经成立：

```text
全局参考
→ 当前合成上下文
→ 依赖排序 / 有限并行
→ 透明组件
→ 融合属性
→ 合成
→ Critic 修正
```

背景硬边界、照片卡片感、组件脱离场景三个主要问题均已在真实任务和内置浏览器中验证改善。
