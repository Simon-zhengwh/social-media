# 六套构图配方

坐标采用 (左, 上, 宽, 高)，画布宽高均为 100。范围是构图指导；超出 0—100 表示图形出血。重要文字保持在画布内。每次选一套；只有用户明确要求时改变默认，不把六套拼在一起。

## L1：超大单体

适合单朵花、单本书、单个物件。

- 标题范围 (8,5,84,15)，整组左右基本对齐，字形有切纸起伏。
- 主图形范围 (8,22,84,63)，一个主体，宽约画面 80%。允许叶片接近边缘。
- 信息范围 (8,89,84,8)，一至三行，按用户事实数量调整。
- 单朵花搭法：不规则椭圆花心 → 12—18 片宽大水滴形花瓣 → 一根弯茎 → 4—6 片大小不同的实色叶片；全部连成一株。
- 对比来自主体尺度、轮廓和颜色，标题可以规整。不要缩成居中小图标。

## L2：侧向出血

适合一个大剪影与非对称留白。

- 主图形范围 (32,-4,76,100)，伸出右边，左侧中下段留空。
- 标题范围 (6,51,54,27)，分 2—3 行，最大的一行略伸向图形。图形和标题允许相接，但标题主要笔画清楚。
- 信息范围 (6,83,48,14)，小字直接排在底色上。
- 人物搭法：头部椭圆 → 连通的肩和躯干 → 两条弯曲手臂 → 两条有屈伸差别的腿。负形区分手臂和腰，不做五官。外轮廓按动作放大，不能随机断肢。
- 骑行搭法：两个同尺度轮环 → 三角车架 → 车把和座位 → 一片连通骑手剪影。最多这些结构，不添加城市风景。
- 可画路时，用另一种已有颜色画一条连续宽曲线，从下方经过；P3 默认草绿车架、浅黄道路。其他三／四色方案也分别指定两种已有色；用户限定两色时用连续底色负形隔开两者。标题空白不被道路切碎。

## L3：同形重复

适合重复舞者、骑手或主题物件。

- 同一个母形出现 3 次，范围依次为 (-8,7,60,38)、(39,28,63,42)、(-7,54,64,40)。人物可以按相同动作错位，不必为每个角色重新设计。
- 图形统一为同一种实色或同一种轮廓处理。用尺度和位置区分节奏，不能三个人用三套风格。
- 标题范围 (8,36,84,24)，利用图形之间的负形；若该处遮挡过多，把整个标题组移到同一块连续底色上。
- 信息范围 (8,91,84,7)。很多文字时缩小第三个图形，为下部扩出空间。
- 具体人物照片不能照此自动重复本人脸；只有明确要求重复肖像才执行。

## L4：字图咬合

适合书展、音乐、文字较短的活动。

- 主图形范围 (10,14,80,75)。默认一个巨大音符／打开的书；抽象活动可用两块大的非文字星芒。
- 标题范围 (5,20,90,49)，2—3 行按词组拆分，左右错位约 6%—12%宽度。字形有切角或粗细变化，阅读顺序从上到下。
- 短信息分别在左上 (6,3,39,12) 和右下 (56,86,38,11)；同一事实只出现一次。信息多时把标题上移，底部留一个完整区域。
- 打开的书搭法：左右两片实色不规则四边形 → 中心弯曲书脊 → 底色切出一个页缝和一个大折角。不要用几十条页线。
- 音符搭法：一个大椭圆符头 → 一根粗长杆 → 一个相连旗形；杆与符头接通。可在其后放一块星芒，星芒只复用已有色。
- 标题覆盖一小段轮廓，主体至少保留一半可见面积。字母不算非文字主体。

## L5：相连图形群

适合花市、果蔬、自然主题。

- 标题范围 (8,5,84,14)，词组可以有轻微错位，辅助文字不压主标题。
- 主图形范围 (8,20,84,66)。一根弯曲分叉茎承载 3—5 个花／果实，单个宽 18%—36%。最大的在中下部，其余错位，所有图形是一套语言。
- 花搭法：一条弯茎 → 四个分叉 → 3—5 组宽大的不规则花瓣 → 小花心 → 3—5 片叶；花心和叶复用茎色，不增加真实植物色。
- 番茄搭法：一根弯折藤 → 3—5 个不规则圆形果实 → 每个果实顶部一个相连的三角萼片群。番茄无高光，不用黑色细描边。
- 信息范围 (8,90,84,8)，直接排在底色上。图形不能把底部信息挤成窄缝。

## L6：贯穿粗带

适合明确要求粗曲线或抽象流动图形的海报；需要具体主题物件时优先 L1—L5。

- 一个连续粗带，从左上出血，横过中段，转入右下，再折向下边；带宽为 14%—22%画面宽度。最多两处大转弯，保留大片内部负形。
- 主标题范围 (14,25,72,32)，2—3 行，字高逐行微调，直接压在粗带与底色上。
- 小信息分两组，范围 (14,67,45,10)、(46,86,43,9)，放在负形里。不能包进标签。
- 粗带不是底板：它应跨过画面不同区域，隐去文字后仍有完整方向和转折；不能只在标题后面画一条横条。
- 若用户要求道路，这条曲线明确作为道路，保持连续，物件与道路复用不同现有色。

## 密集信息的统一处理

保留标题层级和图形系统；把非文字图形收缩 10%—15%或移动，扩出一块辅助信息区域。日期、地点、路线、装备分行排，字号逐级变小。文字不丢、标题不裁、不加卡片、不重复信息。
