# 文字构图的具体做法

图形必需，文字再参与构图。选择一套配方后，用以下一种主方法处理标题，不同时套用所有方法。辅助信息保持同一阅读方向。

| 做法 | 直接执行的方法 | 适用方案 |
| --- | --- | --- |
| 尖角切纸字 | 字体粗壮；少量笔画外缘切角、字腔略不对称；2—3 个词组错位 6%—12%画面宽度 | N01、N23 |
| 饱满手绘字 | 字母／汉字宽度略不同，基线轻微起伏，保持笔画与字腔；整组轻微倾斜，不逐字随机旋转 | N20、N22、N18 |
| 大字压轮廓 | 标题覆盖主体一小段；主体保留至少一半可见面积，标题关键笔画与背景区分 | N19、N10、N17 |
| 负形留字 | 放大主体偏向一侧，文字进入其外侧或内部连续空白，按左对齐组成阅读组 | N12、N08 |
| 图形围合 | 同一类大图形在标题两侧／上下出现，利用大小差别产生节奏，不围成一圈小图标 | N07、N15 |
| 规整文字＋巨大图形 | 标题在顶部直接排，中间图形宽约 80%，底部较小信息。字形与轮廓有手工感 | N04、N13 |

## 中文落地

先分词组，再分行。例如“沿江／慢骑”“周末／花市”“独立／书展”“音乐／现场”“让身体／动起来”。四字标题通常不拆成四个散落字符。大标题可以变化行宽，主要阅读顺序从上到下。用户指定文案与分行时依其要求。

主要字形用粗切纸字或饱满手绘字。用户指定优雅衬线时，可以使用大衬线标题，仍需有独立大图形。不要给一张海报里的标题、日期、路线、装备各选一套字体。

以标题字高 100 为参照：副标题 25—40，日期／地点 14—22，路线／装备 9—13。比例只是层级指导，小字在最终尺寸必须可读。日期不能盖过活动标题。

## 信息分组

将日期和时间放在同一组，地点另起一行，路线和装备为更小字号的一组。分组通过间距和对齐实现，默认没有框、标题条、卡片、丝带、徽章或逐字卡片。主图形内部负形可以放字，但先保证该图形本身成立。

内容太多时让图形腾出 10%—15%的空间，扩展小字区域。原文全部保留；不得复制多份同一日期来填空，不从参考图补无关段落或活动口号。重要文字不出血。
