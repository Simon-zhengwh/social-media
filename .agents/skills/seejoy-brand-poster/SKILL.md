# SeeJoy 喜聚品牌海报

这个 skill 是 SeeJoy 品牌专属设计参考，不是通用餐饮模板。生成 SeeJoy 海报时先读本文件，再按任务读取对应指南：

- 设计、排版、改文案、重新排版：读 `references/layout-guide.md`
- 生成或更换场景底图：读 `references/background-guide.md`
- 需要理解参考图细节或做验收：读 `references/style-analysis.md`
- 需要核对官方 VI 或素材分类：读 `references/vi-and-materials-extract.md`

## 参考图

- `assets/reference-3.jpg`：奶油白纸感 + 厨师人物照 + 红色笔刷优惠区，适合“活动 / 联名 / 主厨到店”。

参考图只用于学习风格，不复制其中的具体文案、价格、日期、人物或 Logo 排版。

## 品牌视觉摘要

- 主色：深绿 `#304521`，牛油果绿 `#5D8343`。
- 强调色：橙 `#EA5514`、红 `#E50012`、橄榄绿 `#748700`。
- 底色：米白 `#EFEDD7`。
- 标题：超大毛笔/手写感中文，允许倾斜 2–6°；主标题通常占画面高度 18%–30%。
- 正文：粗黑体，短句、强层级、左对齐或居中，避免整段长文。
- 菜品：真实摄影优先，保持食物纹理、油光、摆盘和数量；菜品永远比装饰更重要。
- 图形：斜切/撕纸色块、云朵徽章、圆角价格托盘、细手绘线条和少量爱心。
- 批注：1–3 处奶油白或黄色手写短句，像店员贴纸，不要变成正式正文。
- Logo：小而精致，放在顶部角落或底部信息区，保持原始比例，不加白底卡片。

## 使用方式

后端运行时读取 `brand.json`、`references/layout-guide.md` 和 `references/background-guide.md`。生图模型只接收文字版背景指南；设计/排版模型同时接收三张参考图。用户明确提出的风格要求优先于本 skill，未指定时才完整套用品牌规范。

## 生成前检查

1. 是否选择了 SeeJoy 品牌，而不是其他品牌 skill。
2. 菜品图是否清晰、主体完整，第一张是否被指定为主视觉。
3. 文案是否来自用户，价格、折扣、日期是否真实，不得编造。
4. 画布比例是否明确；9:16 优先使用上标题、中菜品、下价格与活动信息的结构。

## 验收检查

- 缩略图状态下仍能一眼看出主标题、主菜品和价格/优惠。
- 深绿、品牌红、奶油白三色关系明确，没有变成普通红黄促销模板。
- 主标题有毛笔手写的力度，不是细黑体或普通系统字。
- 菜品没有被文字、色块或 Logo 大面积遮挡。
- 背景底图里没有生成任何文字、字母、数字、Logo、二维码或水印。
- Logo 使用原始透明素材，比例正确，没有被重绘或加白底。
- 文案层级不超过 5 个主要层级；细节信息集中在底部，不挤压主视觉。
