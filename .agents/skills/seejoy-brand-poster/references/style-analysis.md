# SeeJoy 三张参考图拆解

## 共同设计语言

三张图都不是“干净的品牌 KV”，而是高密度的社媒促销拼贴：

- 色彩：深森林绿负责品牌和稳定感，品牌红负责价格/优惠/行动，奶油白负责文字和呼吸，暖黄负责利益点高亮。
- 摄影：真实菜品、门店和人物照片直接进入版面，保留环境杂光和现场感；菜品纹理比背景精致度更重要。
- 字体：主标题是超大毛笔手写体，笔画有明显粗细变化和飞白；副标题与价格用粗黑体形成硬对比。
- 图形：斜切色块、撕纸边、云朵/花瓣徽章、圆角价格托盘、手绘箭头和爱心，构成“手工贴纸”质感。
- 信息：标题、促销、价格、时间、地址、社交账号可以同时出现，但通过字号、色块和位置形成清晰层级。
- 留白：留白不是极简留白，而是给标题和价格让路的“功能性空白”，通常集中在画面顶部或底部。

## 参考 1：品牌致谢 / 到店邀请

- 竖版 3:4，左上深绿块承载品牌字标和巨大的白色手写标题“谢谢你的到来”，右上为门店夜景。
- 下半部是斜切拼贴：肉类冷柜、整桌菜品、甜品柜，照片之间用白边和斜线分隔。
- 中央偏下放圆形绿色品牌徽章，右下有奶油色手写便签“好食材 才有好相聚”。
- 关键手法：深绿文字块与真实照片形成硬边界；大标题跨两行，第二行略向右下偏移；照片拼贴制造“到店实拍”的丰富感。

## 参考 2：促销 / 自助 / 夜宵

- 满版餐桌菜品照片做底，顶部左上为绿色云朵徽章“儿童5折”，右上为白色品牌字标。
- 中央是整张图最大的毛笔标题“畅吃自助”，前半深绿、后半品牌红，带白色粗描边和阴影。
- 标题下方是奶油白丝带副标题，再往下是红色胶囊“夜宵时间到”和深绿营业时间条。
- 底部是红色圆角价格托盘“$56.99/位”，带黄色皇冠；最底部深绿信息条放活动信息和社交账号。
- 四周散布手写批注和手绘小图标，形成“店员现场推荐”的感觉。
- 关键手法：主标题占据视觉中心 25% 左右高度；价格在下三分之一；红绿对比强，但菜品始终可见。

## 参考 3：活动 / 主厨到店

- 奶油白纸感底，整体像一张贴在墙上的活动海报，外侧有圆角白框。
- 顶部是棕色毛笔字“杜师傅来啦！”配绿色花瓣形品牌徽章；右上角有英文手写小字。
- 左侧嵌入带奶油边框和绿色内框的厨师照片，像拍立得。
- 右侧是斜切红色笔刷块，“4人同行 / 1人免单”用奶油白和暖黄超大毛笔字叠放。
- 下方用黄色高亮条承载第二档优惠，周围是菜品和寿司实拍。
- 关键手法：红色笔刷块不是规则矩形，边缘有干刷飞白；主标题有前后错位和不同颜色，形成节奏。

## 可复用公式

1. 一个主色块 + 一张主菜品大图 + 一到两张辅助照片。
2. 一个 4–8 字的超大毛笔主标题，允许双色、双行、轻微旋转。
3. 一个价格/优惠托盘或徽章，必须落在下半部。
4. 一条底部信息带，承载活动信息、营业时间和社交账号。
5. 一到三处手写批注和少量手绘图标，负责“人味”，不负责信息主体。
6. Logo 小尺寸放在顶部角落或底部信息带，不抢主标题。
