# SeeJoy VI 与素材分类提取

来源：

- `seejoy素材/seejoy喜聚时令鲜火锅VI规范手册.pdf`，26 页。
- `seejoy素材/喜聚SEEJOY_视觉素材分类册.pdf`，7 页。

## 品牌识别

- 标志以 “SEEJOY 喜聚” 为核心，结合火锅社交属性和“喜聚”的情感内核，目标是“东方温暖 + 国际时尚”。
- 中英文字标使用圆润无衬线结构，轮廓柔和，不使用尖锐、卡通或未确认的传统喜庆字形。
- 辅助图形来自标志核心笔画形成的连续纹样；英文手写体用于需要装饰的大面积场景。
- “日日皆欢愉”可作为品牌口号辅助使用，不应替代活动主文案。

## 官方色板

- 深绿 `#304521`：品牌稳定主色，适合大面积品牌区、文字块与信息条。
- 牛油果绿 `#5D8343`：明亮品牌呼应、辅助图形与第二层绿色。
- 米白 `#EFEDD7`：纸感背景、正文与呼吸空间。
- 橙 `#EA5514`：热烈、活动辅助色，可用于优惠与数字。
- 红 `#E50012`：强行动色，仅用于价格、优惠、徽章与关键提示。
- 橄榄绿 `#748700`：少量辅助强调，不替代 Logo 原色。

## 素材分类

1. 品牌识别：品牌徽标、主视觉、圆形图标系统。
2. 火锅主餐台：俯拍全景、斜俯餐桌摆盘。
3. 单品与锅底：牛肉单品、海鲜拼盘、锅底特写。
4. 甜品与寿司：甜品台、寿司档。
5. 门店空间：堂食区、装饰墙。

## 组合建议

- 平台头图：火锅全景 + 牛肉单品 + 锅底，可做三格横图；两张主餐台图可互换。
- 单品推荐：牛肉 + 锅底 + 餐台摆盘，牛肉放首格。
- 四宫格头图：甜品台 + 寿司档 + 火锅全景，空位可用品牌徽标。
- 门店介绍：堂食区 + 装饰墙 + 海鲜拼盘，先空间后菜品。
