# 风格卡片模板化与现有数据初始化

日期：2026-10-26

状态：已实施，数据库初始化及内置浏览器功能验收已完成。执行记录见 [验收记录](2026-10-26-brand-style-template-verification.md)。

## 1. 目标与已确认的选择

把现在的“大文本框”改成有提示的填写表单，并提供一份所有风格共用、可在页面编辑的通用规范。

- 保留喜聚、朵颐两套风格，将现有规范整理进新字段。
- 保留原有 ID、Logo、参考图、封面和历史任务。
- 通用规范修改后，对之后新建的生成任务生效；已有任务保留原快照。
- 第一版只有一套固定填写模板、一份通用规范，不做多级模板继承。

## 2. 页面与填写模板

品牌风格页增加“新建风格”和“通用规范”入口。新建、编辑共用同一张表单，每项都有说明和示例；示例不自动作为实际内容保存。

| 字段 | 填写方式与要求 |
|---|---|
| 风格名称 | 必填，例如“喜聚 · 暖调复古” |
| 风格定位 | 必填，复用现有简介，例如“温暖、复古、轻手作感” |
| 平台与发布用途 | 必填，沿用现有选择器 |
| 配色 | 保留 HEX 色块；增加配色说明，描述主次、用途及是否允许同色系变化；色值与说明至少填写一项 |
| 字体风格 | 必填，说明标题、正文和数字的字体气质 |
| 主体表现 | 必填，例如实拍拼贴、商业摄影、插画 |
| 背景与质感 | 必填，例如奶油白纸感、黑色烟雾棚拍 |
| 排版偏好 | 提供可编辑的默认值：“重点清晰、层级明确，正文不遮挡关键主体” |
| 装饰元素 | 选填，例如手写批注、撕纸边缘；允许明确填写“无” |
| 固定识别元素 | 选填，例如白布幽灵、深色墨镜 |
| 专属禁忌与补充 | 选填，容纳无法归入上述字段的特殊要求 |
| Logo、参考图、封面 | 沿用现有上传、选择和删除功能 |

增加折叠的“规范预览”，展示通用规范、当前风格和平台规则的组合结果。预览不直接编辑，以表单字段为唯一编辑入口。

新卡先保存必填信息，再上传 Logo 和参考图，沿用现有素材接口。

## 3. 通用规范与生成接入

通用规范在独立编辑面板中分成四项，初始化内容为：

- **文案准确**：准确呈现用户指定文字，不编造价格、规则或承诺；涉及优惠时保留完整条件，多个活动分别对应日期与条件。
- **素材使用**：内容素材决定主体身份与关键细节；风格参考只用于视觉表达，不带入旧商品、旧文案或其他品牌标识。
- **Logo 使用**：使用提供的 Logo 时保持图形、字形、比例和原色，不用生成文字替代。
- **可读性**：文字与装饰避开关键主体、脸部和 Logo，不裁切必要信息。

“大标题、一个视觉重点、正文精简”等放在风格的排版偏好中，不作为所有风格的硬性限制。

实现约定：

- MongoDB 新增单条公共配置，保存上述四项、版本号和更新时间；初始默认值只在配置不存在时写入。
- 增加 `GET/PUT /api/brand-rules`；保存时检查版本，避免旧页面覆盖别人刚保存的内容。
- 新增 `POST /api/brands`，扩展现有详情、更新、复制接口及前后端类型，支持结构化风格字段和结构版本。
- 后端统一组装规范，供预览、提示词优化和直接生成使用。新结构存在时，不再重复拼接旧的两段指南。
- 通用规范适用于预设风格、参考图风格和无品牌模式。平台专属限制仍由平台配置提供。
- 新任务保存通用规范正文、版本及风格快照。优化后的提示词进入生图时仍应用任务中的通用规范，但不重新附加完整品牌指南。
- 保持当前多轮改图流程，不在每次改图时重新注入整套规范。
- 未迁移记录和旧任务继续兼容；既有 skill 导入流程不得意外覆盖已经结构化的风格。

## 4. 初始化现有数据库

增加可重复执行的迁移脚本，提供预览和执行两种模式。

执行顺序：**检查当前数据 → 导出备份 → 展示转换差异 → 应用迁移 → 回读核对**。默认只处理尚未迁移的记录，不覆盖之后在页面上的编辑。

| 风格 | 初始化内容 |
|---|---|
| 喜聚 | 保留六个现有 HEX、Logo 和三张参考图；整理暖调复古定位、复古标题与手写批注、真实美食拼贴、奶油白纸感背景、笔刷与撕纸装饰 |
| 朵颐 | 保留四张参考图；整理黑白与奶油黄配色说明、粗体与手写字体、黑色烟雾棚拍、前景菜品、白布幽灵和深色墨镜；不凭空补造品牌 HEX |

同时处理已发现的冲突：

- 喜聚以当前配置色板为基础，配色说明保留同色系协调空间，移除“色值不算数”的冲突表达。
- 朵颐箭头统一为“从菜品附近指向对应菜名”，以原主规范的明确要求为准。
- 喜聚保留小红书图文用途；朵颐依据原规范明确的 9:16，补齐 Instagram 的 Story / Reels 封面用途。
- 通用要求从品牌文本中提取；联系方式限制交给现有平台规则。
- 移除有效生成规范中关于“交付独立图层、蒙版合成”的能力承诺，保留素材一致性的要求。

原始两段指南完整保存在备份及只读原文中。迁移不删除素材、不改历史任务，并通过版本标记避免重复处理。备份失败或检测到迁移期间记录被修改时，停止对应写入并报告原因。

## 5. 验证与交付

- 后端测试覆盖新建、编辑、复制、字段校验、公共规范更新与版本冲突。
- 验证优化与直接生成均使用公共规范，新结构不重复拼接旧指南，无品牌模式也能应用通用要求。
- 验证任务创建后修改公共规范，不会改变该任务的快照。
- 验证迁移保留 ID 和素材关联、保留原文、重复执行不覆盖已整理内容。
- 执行品牌、提示词优化、整图生成相关测试，以及前端 build、lint。
- 页面验收新建、编辑、公共规范保存、规范预览和两套初始化风格。
- 实际执行数据库初始化后，回读核对品牌数量、素材关联及历史任务数量，交付备份位置和迁移结果。

本次默认不调用付费生图；验收确认字段和规范正确传递，不将提示词中的保真要求描述为像素级保证。
